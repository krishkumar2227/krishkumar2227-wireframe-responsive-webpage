ABOUT THE PROJECT

From Wireframe to Webpage

The webpage was developed by first analyzing the wireframe and then converting its visual structure into semantic HTML and CSS.

01

Structure

Semantic HTML elements were used to create a clear and organized webpage structure.

02

Styling

CSS was used for typography, spacing, colors, cards, buttons, and alignment.

03

Responsive

Media queries were implemented to make the webpage adapt to different devices.

WHAT WAS IMPLEMENTED

Key Features

The following features demonstrate the main frontend concepts used in this internship task.

01

Semantic HTML5

Proper semantic elements such as header, nav, main, section, article and footer are used throughout the webpage.

02

Flexbox Layout

Flexbox is used to align navigation, buttons and other flexible content areas.

03

CSS Grid

CSS Grid is used to create organized rows and columns for cards and content.

04

Responsive Design

Media queries allow the webpage to adapt to desktop, tablet and mobile screens.
