# Wireframe to Responsive Static Web Page

## Internship Task

This project was developed as part of a frontend web development internship task.

The objective was to convert a wireframe concept into a functional static webpage using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- Visual Studio Code
- Google Chrome Developer Tools
